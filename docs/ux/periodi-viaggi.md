# Periodi dei viaggi: quando è andato Rick e quando andare

Generato il 6/11/2026 dai markdown italiani (`src/content/viaggi`) e dai `mesiConsigliati` dei TripMeta (`src/content/viaggi-dati`).

- **Quando è andato** = campo «Periodo del viaggio»: solo il periodo reale. Se non è registrato resta vuoto (la pagina non lo mostra). Le note «anno da confermare» le toglie il parser.
- **Mesi reali** = `mesiDelViaggio(slug)` (parser `mesiDaPeriodo`): un mese solo quando il periodo è unico e breve.
- **Periodo consigliato** = «Quando andare» / «Periodo migliore» della Scheda pratica (testo già pubblicato, accorciato qui).
- **Mesi consigliati** = `TripMeta.mesiConsigliati`, letti a mano dal testo consigliato; `mesiConsigliatiDelViaggio(slug)` li espone al Travel Finder. Vuoto = il testo non dà mesi chiari.
- **Prima** = il vecchio «Periodo del viaggio» quando è stato svuotato o cambiato perché conteneva una stagione consigliata.
